MANUAL & QUICK GUIDE
FEATURES

BIG SOUND

Lots of computing power to deliver rich sounding engines, in an 8 voice package.
One voice can have up to 8 oscillators depending on the engine, which means 64 oscillators playing at once!

POLYPHONIC

Coral features 8 full voices with independent filter, amplifier and modulation envelopes.
Individual FX sends and individual parameters can be set per voice! 

You can play polyphonically using only 1 CV and 1 Gate.
Coral will allocate a new voice every time it reads a new note on the V/Oct input.

MULTIENGINE

Different sound engines can be assigned to each voice from the 10 available.
Different set of engines are available from our firmware updater.

MULTIPART

The 8 voices can be freely split into different parts. Every single parameter (filter, envelope settings, engine, FX sends, pan, etc.) can be independently set for each part or voice to create complex patches out of the box.

SAMPLE PLAYBACK

CORAL supports almost any kind of wav file: 16, 24 and 32 bit mono and stereo files, no limit to playback time!
Add overdrive to your samples, sculpt them using the filter and envelopes, pitch them up and down in tune and even modulate the sample file or folder in real time using the CV inputs or CC MIDI commands!

CUSTOM WAVETABLES

You can load any wavetable .wav file to the SD card for the Wavetable engine. The wavetable can be morphed in 3 dimensions. Use our OXI Wave APP to create and edit 3D wavetables.

MIDI INTEGRATION

Control any part’s parameter via MIDI CC, from FXs sends to sample selection.
Combine it with CV signals for a killer compact combo.

EFFECTS

Space engine to create deep atmospheres and rich ensemble chorus.
Every effect send can be set per voice.

MPE

Coral has been upgraded with MPE support, turning it into a full polyphonic 8-voice MPE synthesizer.
Check it out yourself!

HOW TO PLAY IT
HOW TO PLAY
MIDI

Like a full 8 voice polyphonic synthesizer

Connect a MIDI Controller, set the right MIDI channel and you are ready to go.

1 part of 8 voices

Like a Groovebox

Assign different MIDI channels to the different VOICES to create separate PARTS.

You can have a full drum kit with a different sample per voice or mix samples with synth engines to create a full track. Simply assign a different engine to each of the parts.

You can even set a different engine or a different .wav sample per voice!

CV

Like a full synth Voice

Play all voices in unison: all voices playing the same note for drones and thick textures.

Or polyphonically: Coral will allocate a new voice every time it reads a new note on the v/oct input: arpeggios, strummed chords or pads with long decayed notes.

It’s possible to trigger the internal envelopes with the TRIG input or directly control the amplifier level with the AMP CV.

Remember, Coral allows you tweak each voice’s engine, parameters and attenuators separately, encouraging to create richer and more complex patches.

Like Multipart CV

Once you have voices grouped in different parts, you can distribute the modulation signals across them using the PART CV.

Example:
if you have two parts, the first part will be addressed if the voltage in part CV is between 0 and 2.5V or the second one if the voltage is between 2.5 and 5V.

MOTIVATION

The introduction of the Mutable Instruments Plaits module was a revolution in terms of compact, multi-engine synth voice modules. Thanks to MI open source contributions, we have taken some of their algorithms and put them into a compact package that contains 8 “instances” of this module with custom engines and new ingredients like independent envelopes and filter per voice, FXs, full MIDI implementation and a colorful and organic interface. On top of that, you have custom wavetables and a sample playback engine also available per voice.

But we didn’t want just another polyphonic synth so, to allow you take the most of every voice, we’ve introduced a fully flexible multipart concept. This means you can arrange and use the 8 voices as you want: 8 monophonic parts, 1 polyphonic part of 8 voices, or any combination of that, like 2 polyphonic parts of 3 voices each plus 2 monophonic voices in the same module.

This makes the CORAL a versatile and powerful Polysynth, Drum Machine, Groovebox and Sound Exploration module at the same time!

We haven’t stop here and we’ve added more engines with different firmware availables like we have been doing with the OXI ONE!

OXI ONE + CORAL

CORAL is the perfect companion for the OXI One or any other polyphonic and multitrack sequencer. Lot of power for your Modular rig in a very compact device.
