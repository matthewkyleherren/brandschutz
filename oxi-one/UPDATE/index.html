Update Instructions

– Backup first if you come from a 1.X version.

Download the correct OXI Desktop App version for your computer OS and let it automatically update your device.

Alternatively you can:

– Download the latest firmware (available on the top of this page).

– Press OXI ONE UPDATE.

– Select the .syx firmware file you have previously downloaded.

– Wait for the OXI ONE to restart.

Note: If the process gets stuck somewhere you can always press Mute while switching on to start in Update mode.

MAC users: if your OS is not supported, you can use the Sysex Librarian App to send the firmware file to your OXI One. You would need to manually turn it on in Update mode.

Backup Instructions

To get the projects from your OXI One:

– Go to the Poject tab, select the project number

– Press “Get project” and wait.

– Repeat with every project you want to backup.

Note: Project data can be found in the OXI_Files folder that is created in your desktop when you open the app.

 

To send the projects back to your OXI One:

– Select the project slot you want to send the project to.

– Press “Send project”, browse in your OXI_Files folder the project file Project *.oxipro and wait until it’s sent.

– Repeat with every project you want to send.
